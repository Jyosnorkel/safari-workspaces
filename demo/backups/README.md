# Demo tab backups

Both JSON files pass Tabby's actual backup decoder and contain the same 30 public URLs, interleaved across five projects: Safari extension development, a London weekend, photography, a personal website and hackathon preparation. No credentials or personal browsing data are included. Availability, redirects and titles of remote pages have not been checked; Safari will replace saved example titles with each live page's title after loading.

- `tabby-demo-30-tabs.json`: no preset groups; use for the cluttered starting point and a real AI organisation demo.
- `tabby-demo-30-tabs-organised.json`: five hand-authored preset groups; use for snapshot screenshots. These groups are illustrative, not model output. Restoring URLs does not necessarily hydrate live organisation from snapshot groups.

Use the import picker to save without opening tabs. To open the demo, deliberately drop the ungrouped JSON into Tabby's backup drop area; it restores the 30 URLs in a new normal window and keeps existing windows open. Wait for pages to load, then refresh/scan that window. AI requests require your normal opt-in and sharing consent and consume the configured request allowance. No inference has been performed to create these files.

For recording: show the mixed tabs, scan, request real AI organisation, make a meaningful correction, then save/export a snapshot. Do not represent the preset organised file as a live AI result. Existing project restrictions on closing Safari windows/tabs remain in force.
